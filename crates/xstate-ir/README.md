# xstate-ir

Language-neutral intermediate representation (IR) for [restingstate](https://github.com/yestechgroup/restingstate) statecharts. Defines the serializable `Machine` schema that `xstate-parser` produces and that `xstate-codegen` and the runtimes consume.

See the [root README](../../README.md) for an overview and [docs/runtime-paths.md](../../docs/runtime-paths.md) for the runtime-path decision guide.
