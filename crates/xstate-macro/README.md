# xstate-macro

`#[xstate("path/to/machine.ts")]` proc macro for [restingstate](https://github.com/yestechgroup/restingstate). Compiles XState TypeScript machine definitions into native Rust state machines at build time via `xstate-parser` and `xstate-codegen`.

See the [root README](../../README.md) for an overview and [docs/runtime-paths.md](../../docs/runtime-paths.md) for the runtime-path decision guide.
