# xstate-backend-native

Single-threaded, WASM-compatible actor system backend for [restingstate](https://github.com/yestechgroup/restingstate). Implements the `xstate-core` backend traits synchronously for browser and embedded targets.

See the [root README](../../README.md) for an overview and [docs/runtime-paths.md](../../docs/runtime-paths.md) for the runtime-path decision guide.
