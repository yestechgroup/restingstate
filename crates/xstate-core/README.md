# xstate-core

Pure Rust runtime for [restingstate](https://github.com/yestechgroup/restingstate) statecharts: the `Machine` trait, snapshots, `StateValue`, the `Interpreter`, and backend traits for actor systems. No TypeScript or JavaScript dependency.

See the [root README](../../README.md) for an overview and [docs/runtime-paths.md](../../docs/runtime-paths.md) for the runtime-path decision guide.
