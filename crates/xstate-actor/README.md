# xstate-actor

Tokio-based async actor system for [restingstate](https://github.com/yestechgroup/restingstate). Spawns `xstate-core` machines as concurrent actors with `spawn`, `send_to`, and parent messaging.

See the [root README](../../README.md) for an overview and [docs/runtime-paths.md](../../docs/runtime-paths.md) for the runtime-path decision guide.
