How it works

When WASM bindings are available, the JavaScript API matches the NAPI-RS API:

// Load WASM module
const wasm = await loadWasm('xstate_napi.wasm');

// Create machine from IR JSON
const machine = new wasm.JsMachine(machineIrJson);

// Get current snapshot
const snap = JSON.parse(machine.snapshot());
console.log(snap.value, snap.context);

// Send events
const result = machine.send(JSON.stringify({ type: 'TOGGLE' }));
if (result) {
  const newSnap = JSON.parse(result);
  console.log(newSnap.value); // 'active'
}

Build Instructions

# Build for WASM (requires wasm-bindgen — planned)
cargo build -p xstate-napi --target wasm32-unknown-unknown

# Package for web
wasm-pack build crates/xstate-napi --target web

# Serve
npx serve examples/js-wasm
